Диаграммы поведения системы "Умный планировщик уборки"
Обзор
Данный раздел содержит диаграммы поведения системы, описывающие взаимодействие пользователей с приложением "Умный планировщик уборки" и внутренние бизнес-процессы автоматизации домашней уборки.

Структура проекта

│   ├── complete_task_sequence.puml    # Завершение уборки

    └── use_case_diagram.puml          # Диаграмма вариантов использования

    Use Case Диаграмма
Акторы системы:
Пользователь - основной пользователь приложения:

Владелец дома/квартиры, который планирует и выполняет уборку

Использует веб-приложение или мобильное приложение

Получает умные рекомендации по оптимизации уборки

Основные Use Cases (Варианты использования):
1. Управление задачами уборки
Добавление новой задачи уборки - создание задачи с указанием комнаты, типа уборки, сложности и срока

Пометка задачи как выполненной - завершение уборки с указанием фактического времени выполнения

Редактирование задачи уборки - изменение параметров существующей задачи

Удаление задачи уборки - удаление ненужных или ошибочных задач

Просмотр списка задач - отображение всех активных задач уборки

2. Расширенные возможности просмотра
Фильтрация задач по комнатам - показ задач только для выбранной комнаты (кухня, ванная, спальня и т.д.)

Поиск задач - поиск по названию или описанию

Сортировка задач - сортировка по приоритету, сроку, комнате

3. Автоматические функции
Автосохранение изменений - автоматическое сохранение при редактировании

Валидация данных - проверка корректности вводимых данных

Отношения между Use Cases:
Include отношения (включение):

Добавление задачи → Валидация данных

Редактирование задачи → Валидация данных

Редактирование задачи → Автосохранение изменений

Extend отношения (расширение):

Просмотр списка задач ← Фильтрация задач по комнатам

Просмотр списка задач ← Поиск задачи

Просмотр списка задач ← Сортировка задач

Диаграммы последовательности
1. Создание задачи уборки

Описание: Процесс создания новой задачи уборки, включая:

Ввод данных пользователем (комната, тип уборки, сложность, срок)

Валидацию данных на стороне сервера

Сохранение задачи в базу данных

Создание связей с категориями уборки

Планирование уведомлений

Расчет следующей рекомендуемой даты уборки

Обновление интерфейса пользователя

Ключевые особенности для уборки:

Учет типа помещения (кухня требует более частой уборки)

Расчет сложности и предполагаемого времени

Автоматическое планирование повторяющихся задач

Интеграция с системой напоминаний

2. Завершение задачи уборки

Описание: Процесс отметки уборки как выполненной, включающий:

Подтверждение выполнения пользователем

Фиксацию фактического времени уборки

Обновление статуса задачи в БД

Запись в историю выполненных уборок

Обновление статистики комнаты

Автоматическое создание следующей задачи для рекуррентных уборок

Расчет "уровня чистоты" комнаты

Визуальную обратную связь пользователю

Особенности для уборки:

Трекинг реального времени выполнения

Обновление статистики чистоты комнат

Автоматическое планирование следующей уборки на основе частоты

Мотивационные сообщения по завершению

3. Фильтрация задач по комнатам

Описание: Процесс фильтрации списка задач уборки по выбранной комнате:

Загрузка списка комнат пользователя (с кэшированием)

Выбор комнаты для фильтрации

Выполнение SQL-запроса для получения задач конкретной комнаты

Получение статистики уборки по выбранной комнате

Форматирование и отображение результатов

Обновление интерфейса с фильтрованным списком

Оптимизации:

Кэширование списка комнат для быстрого доступа

Эффективные SQL-запросы с использованием индексов

Предварительная загрузка статистики комнаты

4. Ежедневный процесс уборки

Описание: Комплексный сценарий типичного дня пользователя:

Этап 1: Утренний обзор
Пользователь открывает приложение

Система показывает план уборки на сегодня

Приоритезация задач на основе частоты уборки и срочности

Визуальное выделение срочных комнат

Этап 2: Выполнение уборки
Пошаговое выполнение задач с таймером

Фиксация начала и окончания каждой уборки

Обновление прогресса в реальном времени

Мотивационная обратная связь

Этап 3: Вечерняя аналитика
Генерация отчета за день

Расчет продуктивности (время уборки, количество комнат)

Визуализация достижений

Сравнение с предыдущими днями

Этап 4: Планирование на завтра
Автоматический анализ выполненных задач

Формирование рекомендаций на следующий день

Планирование напоминаний

Балансировка нагрузки по дням недели

Используемые инструменты
PlantUML - очень быстрый и удобный инструмент для представления диаграмм
